# Rendezvous

## What this is

Doing some thought excercises from the newsletter [Rendezvous with Cassidoo](https://cassidoo.co/newsletter/).

## Available scripts

```shell
pnpm run scaffold  # scaffold a new exercise
pnpm run test      # run tests
pnpm run lint      # run linter and formatter checks
pnpm run typecheck # run TypeScript type checking
```

To run an individual exercise directly:

```shell
oxnode excercises/<date>/bin/index.ts
```
